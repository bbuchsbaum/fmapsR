# Build Descriptors from a Domain Basis

Build Descriptors from a Domain Basis

## Usage

``` r
fm_descriptors(domain, method = c("hks", "wks"), ...)
```

## Arguments

- domain:

  \`fm_domain\` with basis/eigenvalues.

- method:

  Descriptor family: \`"hks"\` or \`"wks"\`.

- ...:

  Additional method-specific arguments.

## Value

Numeric descriptor matrix.
