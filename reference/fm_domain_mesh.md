# Mesh Domain Adapter

Mesh Domain Adapter

## Usage

``` r
fm_domain_mesh(vertices, faces = NULL, measure = NULL, operator = NULL, ...)
```

## Arguments

- vertices:

  Vertex matrix.

- faces:

  Optional face index matrix.

- measure:

  Optional sample measure weights.

- operator:

  Optional mesh operator.

- ...:

  Passed to \[fm_new_domain()\].

## Value

An \`fm_domain_mesh\` object.
