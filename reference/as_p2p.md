# Convert Functional Map to Pointwise Map

Convert Functional Map to Pointwise Map

## Usage

``` r
as_p2p(fit, reverse = FALSE, use_adj = FALSE)
```

## Arguments

- fit:

  \`fm_fit\` object.

- reverse:

  If \`TRUE\`, return source-to-target mapping.

- use_adj:

  If \`TRUE\`, use adjoint-style embeddings.

## Value

Integer index vector representing nearest-neighbor pointwise map.
