# Load a Bundled Example Mesh Pair

Load a Bundled Example Mesh Pair

## Usage

``` r
fm_example_mesh_pair(
  name = c("posed_tube", "tosca_cat1", "tosca_cat2", "tosca_cat6", "tosca_cat10")
)
```

## Arguments

- name:

  Example mesh-pair name. Available options are \`"posed_tube"\`,
  \`"tosca_cat1"\`, \`"tosca_cat2"\`, \`"tosca_cat6"\`, and
  \`"tosca_cat10"\`.

## Value

List containing \`source\`, \`target\`, \`truth\`, and \`metadata\`.
