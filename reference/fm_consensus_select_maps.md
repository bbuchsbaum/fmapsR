# Select Consensus Maps by Confidence Threshold

Select Consensus Maps by Confidence Threshold

## Usage

``` r
fm_consensus_select_maps(object, min_confidence = 0.5)
```

## Arguments

- object:

  \`fm_consensus\` object.

- min_confidence:

  Minimum confidence threshold in \`\[0, 1\]\`.

## Value

Named list of consensus maps passing threshold.
