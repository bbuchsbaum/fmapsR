# Create a Functional-Map Network

Create a Functional-Map Network

## Usage

``` r
fm_network(domains, maps = NULL, directed = TRUE)
```

## Arguments

- domains:

  Named list of \`fm_domain\` objects.

- maps:

  Optional named list of maps keyed as \`"i-\>j"\`.

- directed:

  Whether to treat edges as directed.

## Value

\`fm_network\` object.
