# Build Network Report from Sync Output

Build Network Report from Sync Output

## Usage

``` r
fm_network_report(x, post = NULL)
```

## Arguments

- x:

  \`fm_network_fit\`, or \`fm_network\` if \`post\` is provided.

- post:

  Optional post-sync \`fm_network\` when \`x\` is a pre-sync network.

## Value

\`fm_network_report\` object.
