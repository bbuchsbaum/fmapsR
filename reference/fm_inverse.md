# Invert a Functional Fit

Invert a Functional Fit

## Usage

``` r
fm_inverse(fit, method = c("pseudoinverse", "transpose"))
```

## Arguments

- fit:

  \`fm_fit\` object.

- method:

  One of \`"pseudoinverse"\` or \`"transpose"\`.

## Value

\`fm_fit\` object with swapped source/target direction.
