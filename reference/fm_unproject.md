# Reconstruct Functions from Domain Basis Coefficients

Reconstruct Functions from Domain Basis Coefficients

## Usage

``` r
fm_unproject(domain, coef, basis = NULL)
```

## Arguments

- domain:

  \`fm_domain\` object.

- coef:

  Basis coefficients.

- basis:

  Optional basis list override.

## Value

Reconstructed function values.
